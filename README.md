# CodeMate Ultimate — Language-Aware Practice Edition

## Run
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Install Live Server if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Language-aware practice
Choose your preferred language in the top bar. Practice problem code and its line-by-line walkthrough use that selected language. Verified language-specific solutions are included for common starter problems (Hello World, sum of two numbers, even/odd, largest of two numbers, and factorial) across the supported languages. For other problems, the site deliberately shows a native-language starter scaffold and labels it as incomplete rather than incorrectly displaying Python as another language.

## Languages
Java, Python, JavaScript, C, C++, C#, Go, Rust, Ruby, PHP, and SQL.

## Notes
- No online compiler is included in this edition.
- Sign-in/progress storage is browser-local demo storage, not secure server-side authentication.
- The generated walkthrough explains code structure line by line; always test and verify programs in the language's own runtime.
